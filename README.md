# Pizza Order Calculator (TMA3084 SELAB - Lab 1)

A simple CLI-based Dart program that calculates pizza orders based on size and quantity.

## Features
- Displays pizza prices (Small: $5, Medium: $7, Large: $10).
- Takes size and quantity input from user.
- Employs a `switch` statement for price calculation.
- Uses a `while` loop for input validation and continuous ordering.

## How to Run
```bash
dart run pizza_order.dart
